## Changelog

### 2026-09-20
**Added**
- Projet créé (version 0.1.0 dans `package.json`). Stack retenue : cœur web TypeScript + React 19 + Vite 8, Electron 44 pour Windows, Capacitor 8 pour Android. Choix motivé par l'environnement (Node 24 seul ; pas de Flutter, Visual Studio ni .NET moderne) et par Hanzi Writer (JS) pour l'écriture des traits.
- Modèle d'apprentissage : 2000 mots en 6 paliers cumulés (100/200/400/600/1000/2000), 14 thèmes avec une teinte OKLCH chacune (`data/themes.json`). Cartes teintées par thème pendant l'apprentissage, neutres une fois le mot maîtrisé (4 compétences à intervalle ≥ 21 jours).
- Répétition espacée (variante SM-2) par mot et par compétence : lecture, écoute, écriture, prononciation (`src/core/srs.ts`), constructeur de session mêlant révisions dues et nouveaux mots, alternance des thèmes au sein d'un palier (`src/core/session.ts`).
- Cinq modes : découverte (tout affiché + animation des traits), lecture (caractères → sens, QCM), écoute (audio → sens, QCM), écriture (tracé trait par trait sans modèle, corrigé par Hanzi Writer, bouton « Voir le modèle » qui passe la carte en « à revoir »), prononciation (modèle vocal, enregistrement micro, ré-écoute, auto-évaluation ; vérification par reconnaissance vocale sur Android).
- Écrans : accueil (barres de progression par palier : en cours / maîtrisés), session, liste des mots (filtres palier/thème, détail dépliable), réglages (nouveaux mots/jour, révisions max, pinyin/zhuyin, police Kai, thème clair/sombre, vitesse de la voix, compétences activées, export/import/réinitialisation).
- Couche plateforme : stockage (fichier JSON via IPC Electron / Filesystem Capacitor / localStorage), synthèse vocale (voix zh-TW Windows Hanhan/Yating/Zhiwei ou TTS Android), reconnaissance vocale (plugin Capacitor, Android), enregistreur MediaRecorder.
- Electron : protocole privilégié `app://` servant `dist/`, préchargement isolé, export/import via boîtes de dialogue, mode `--smoke` pour vérifier le chargement en CI. Config electron-builder (NSIS + portable), icône 日 générée (PNG/ICO).
- Android : plateforme Capacitor ajoutée, permissions micro + `queries` RecognitionService dans le manifeste, icônes/splash générés (`@capacitor/assets`), script `scripts/android-build.mjs` (JDK d'Android Studio, SDK local).
- Pipeline de données : liste maîtresse paliers 1-4 (600 mots) écrite à la main par thème ; paliers 5-6 proposés par 14 agents thématiques puis fusionnés/dédoublonnés (`scripts/merge-candidates.mjs`, exactement 400 + 1000 mots) ; enrichissement (pinyin, catégorie, sens FR, note Taiwan, exemple) par 8 agents ; validation (`scripts/validate-words.mjs` : syllabes pinyin, caractères simplifiés, exemples, croisement CC-CEDICT y compris prononciations « Taiwan pr. ») ; génération (`scripts/build-data.mjs`) du `words.json` avec zhuyin dérivé du pinyin et des données de traits Hanzi Writer par palier.
- Bibliothèque pinyin → zhuyin (`scripts/lib/pinyin.mjs`) : marques de ton, ton neutre (˙ devant), ü, découpage de syllabes collées.
- README (FR) : fonctionnalités, commandes, pipeline de données, architecture, notes voix/licences.

### 2026-09-21
**Changed — pivot vers un jeu (roguelite deckbuilder / card battler)**
- L'app se présente maintenant comme un jeu : le joueur, fraîchement arrivé à Taïwan, affronte des situations du quotidien avec son **deck** de cartes Mots. Camp (accueil) : compteur `DECK: n/2000`, « Learn cards », « Start a run » (10 cartes minimum), reprise d'un run en cours, liens Deck / Practice / Settings.
- **Cartes** : symboles seuls (`src/ui/cards.tsx`) ; bandeau de couleur de thème (neutre une fois maîtrisé). Main en éventail : carte centrale agrandie, touchée une fois pour la centrer, deux fois pour la jouer ; clavier ← → Entrée.
- **Déblocage** : une carte rejoint le deck quand elle a été tracée (flux découverte en pointillé) ; ordre de fréquence avec thèmes alternés dans chaque palier (ordre rendu stable : tour de rôle sur le palier entier, puis filtrage).
- **Run** (`src/game/`) : carte roguelite à 8 rangées (départ → boss), 2-4 nœuds par rangée, chemins au choix, générée par graine (mulberry32) ; nœuds rencontre / élite / repos / boss ; 16 situations (supérette, marché de nuit, métro, propriétaire, clinique, bureau…) disponibles seulement si le deck fournit assez de phrases de leur thème ; boss « entretien de résidence » toutes catégories.
- **Combat** : phrases à trou tirées des 2000 exemples, découpés en mots du dictionnaire ; tout mot du deck présent dans une phrase peut devenir le trou. 5 PV par run, −1 par erreur ; rencontre 6 lignes, élite 9, boss 12 ; la phrase complète est lue après la réponse. Emplacement « adversaire » prévu pour de futurs dessins de personnages animés.
- **Récompenses** : 1 carte (élite : 2) à choisir parmi 3, tracée sur place, ajoutée au deck immédiatement ; repos : +2 PV.
- **Difficultés** : Newcomer (carte centrale avec pinyin + sens, phrase traduite), Seasoned (symboles + pinyin), Resident (symboles seuls).
- État persistant : deck (`unlocked`), run en cours (`run`), compteurs de runs ; migration automatique des sauvegardes (les mots déjà tracés deviennent le deck initial).
